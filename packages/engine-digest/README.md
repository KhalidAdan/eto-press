# @eto-press/engine-digest

*A reading list, not a retelling.*

The day's new links from the masthead's feeds, grouped into the
sections the masthead's `side` labels name, each item the outlet's own
front door with the feed's own blurb. Nothing is composited, nothing is
judged; the digest arranges what the outlets said and links to where
they said it. A morning with no new links is `NoEdition`: no file, no
mail, the press rests.

Declare it with `[engine] use = "digest"` in `eto.toml`. On this engine
a source's `side` is its section, not its politics. It never needs
Ollama.
