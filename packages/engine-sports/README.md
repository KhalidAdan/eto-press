# @eto-press/engine-sports

*Signed columns beside the leagues' own links.*

One paper, two corpus origins: bylined columns the editor leaves in
`desk/` (a `by:` line names the author), and the day's results and
stories from the leagues' own feeds, grouped by the masthead's `side`
labels — which on this engine name leagues, not sides. Zero models.

Declare it with `[engine] use = "sports"` in `eto.toml`. It never needs
Ollama.
