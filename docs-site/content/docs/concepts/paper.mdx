---
title: What is a paper?
description: A paper is a directory. The press is what visits it each morning.
---

A **paper** is an ordinary directory on your disk:

<FileTree>
- my-paper
  - eto.toml — the nameplate and plumbing
  - sources.toml — the editorial line
  - models.lock.json — pinned model digests
  - desk/ — editor-authored copy (optional)
  - db/
    - eto.sqlite — the journal
    - exports/ — diffable JSONL of the tables that are truly yours
  - archive/
    - 2026-08-15.md — one file per edition, append-only, forever
    - 2026-08-16.md
  - site/ — the rendered web edition
  - logs/ — one log per morning
</FileTree>

The **press** is software that visits this directory each morning. It reads
your configuration, prints your edition, and leaves. The press updates like
any dependency — deliberately, with a changelog, by your hand — and your
paper's content never lives inside it. A paper survives any press upgrade
untouched, and a generation-1 paper keeps printing forever without
acknowledging generation 2 exists.

## The two files that are yours

**`sources.toml` is the editorial line** — which outlets your paper reads and
where each stands. The press enforces the balance *you* configured and no
other. Change the file, change the paper. Full schema:
[the sources file](/docs/reference/sources-file).

**`eto.toml` is the nameplate** — name, motto, the single accent color, which
local models print your paper, how the mail goes out, which
[engine](/docs/concepts/engines) prints it. Every field has a neutral
default: a paper with no `eto.toml` is an unnamed local paper, never a copy
of someone else's. Full reference:
[configuration](/docs/reference/configuration).

## The journal and the archive

**The archive is files; the journal is the newsroom.** Published editions are
plain markdown in `archive/`, never rewritten. The journal (`db/eto.sqlite`)
holds every fetch, verdict, draft, and verification — it can be deleted and
rebuilt from the world, except for two tables that are genuinely yours:
your corrections and your source-health history. Those are exported as
diffable JSONL and backed up on every run. See
[Backups and the journal](/docs/guides/backups).

## The guarantees the directory carries

- **The archive is fixed.** Corrections run in today's edition, dated,
  pointing back — the old file is never touched.
- **The journal resumes.** Every expensive unit of work is cached; recovery
  from any crash is the same command, run again.
- **Nothing phones home.** No analytics, no telemetry, no reader tracking,
  in any tier, on any page, in any email.
