---
title: Configuration — eto.toml
description: Every field, every default. A missing file is a valid paper.
---

`eto.toml` is the paper's nameplate and plumbing. **Every field is
optional**, and every default is neutral: a paper with no `eto.toml` at all
is an unnamed Tier-1 local paper — never a copy of any real paper's
identity, address, or machine.

## `[paper]`

| Field | Default | Meaning |
| --- | --- | --- |
| `name` | `"your paper"` | The wordmark, the email sender name, the `<title>`. |
| `motto` | *(a prompt to write one)* | Rendered under the wordmark and in the email header. |
| `description` | *(the generic brief description)* | Meta description, RSS channel description, subscribe copy. |
| `site_url` | `"http://localhost"` | Canonical URLs, RSS links, the email's "read on the web" link. |
| `accent` | `"#7f1d1d"` | The single accent color — spent only on the paper's own voice (the differ label, balance notes, the wordmark's full stop), never on the news. |
| `constitution_url` | *(empty)* | Generation 3. Where the paper's constitution is published; the about page links it. Empty means the page names none. |

```toml
[paper]
name = "eto"
motto = "Each story. Every side."
site_url = "https://eto.news"
accent = "#7f1d1d"
```

## `[engine]`

| Field | Default | Meaning |
| --- | --- | --- |
| `use` | `"eto"` | Which engine prints this paper when it declares no sections — a name from the press's built-in registry (`eto`, `desk`, `letter`, `digest`, `sports`, `wrap`). Generation 2. |

## `[[section]]` — generation 3

A paper is sections: each printed by one engine from its own source file,
bound into one morning in the order declared here. **A paper with no
`[[section]]` blocks is a paper with one section**, printed by `[engine]
use` from `sources.toml`, and it renders exactly as generation 2 rendered
it — every existing paper is valid as it stands.

| Field | Default | Meaning |
| --- | --- | --- |
| `slug` | *(required)* | The section's address: `[a-z][a-z0-9-]*`, unique in the paper. Names the section on the page, its desk directory (`desk/<slug>/`), and its journal rows. |
| `engine` | *(required)* | Which engine prints this section — a name from the registry above. |
| `name` | the slug | The printed name: the section heading on the page, in the archive, and in the mail. |
| `masthead` | `sections/<slug>.toml` | The section's source file — `sources.toml`'s shape, one per desk. What `side` means in it is the engine's to say. |

```toml
[[section]]
name = "Current events brief"
slug = "brief"
engine = "eto"
masthead = "sources.toml"

[[section]]
name = "Sports"
slug = "sports"
engine = "sports"
```

Two rules the press enforces at preflight: a feed URL may be listed under
one section only (the journal keys an item by its link and gives it one
side), and every section's engine must be one the press was built with.
A section whose engine returns no edition is printed as absent — a line on
the page and a warning in the report — while the others print; a morning
where every section is silent prints nothing at all.

The desk is per section once sections are declared: `desk/<slug>/`
instead of `desk/`.

## `[models]`

| Field | Default | Meaning |
| --- | --- | --- |
| `ollama_url` | `"http://localhost:11434"` | Where the local model server answers. |
| `match` | `"qwen3:4b-instruct"` | The judge: high-volume, one-word answers, no thinking mode. |
| `composite` | `"qwen3:8b"` | The compositor: low-volume, longer deliberation. |
| `composite_num_ctx` | `8192` | The compositor's context window. |

Digests for the named models are pinned in `models.lock.json` by the first
`eto models pull` (or the first print, if no lock exists yet); drift stops
the press. Change a model name here and the press re-judges and
re-composites as needed — the caches key on model and prompt.

## `[mail]` — tier 3 only

| Field | Default | Meaning |
| --- | --- | --- |
| `region` | `"ca-central-1"` | The SES region. |
| `domain` | *(empty)* | The sending domain. Empty means mail is unconfigured. |
| `from` | *(empty)* | The From header, e.g. `"eto <brief@eto.news>"`. |
| `from_fallback` | *(empty)* | A verified address used loudly until the domain identity verifies. |
| `contact_list` | `"eto-readers"` | SES contact list name (a press convention, not identity). |
| `topic` | `"morning-edition"` | The list topic readers subscribe to. |
| `config_set` | `"eto-mail"` | SES configuration set. |
| `email_edition` | *(undeclared)* | The morning delivery switch, `true` or `false`. Undeclared here, the `email_edition` flag in the first section's source file decides, where generation 2 kept it. |

## `[backup]`

| Field | Default | Meaning |
| --- | --- | --- |
| `dir` | `"backups"` | Where journal snapshots land. The default is inside the paper — point it at a different disk when you configure it for real. |
| `keep` | `14` | How many rotating snapshots to keep. |

## What is deliberately absent

The algorithm's tunables — the story cap, the density floor, the word
budgets, the pair-judging thresholds — are not configuration. They are the
engine's doctrine in executable form: the paper's journalistic standards,
not knobs. The masthead is yours; the standards are the press's.

There is also no provider-selection key yet. One inference provider exists,
Ollama, and `[models]` is what it reads; a key to choose between providers
arrives with the second one.
