<Callout>
  Semantic anatomy ships with **generation 2** — the markup contract a
  [skin](/docs/concepts/skins) styles against.
</Callout>

Markup names structure; the theme names appearance. These class names are
the contract: stable, styleable, and never carrying visual decisions
themselves.

## The voices

| Class | Meaning |
| --- | --- |
| `prose` | The news speaking — body text, differ items, correction notes. |
| `instrument` | The paper speaking — labels, dates, sources, the report. |
| `instrument--quiet` | The instrument voice, dimmed. |
| `instrument--label` | Uppercase, letter-spaced label form. |
| `instrument--strong` | The medium weight for section labels. |
| `accent` | The paper's single color — differ labels, balance notes, the wordmark's full stop. Never the news. |
| `link` | Every inline link's underline treatment. |

## The story

| Class | Element |
| --- | --- |
| `story` | The article container. |
| `story__headline` | The headline. |
| `story__body` | Each body paragraph. |
| `story__differ-label` | "Where the accounts differ". Absent when the story has no differ block (a desk entry). |
| `story__differ` / `story__differ--list` / `story__differ-item` | The differ content — paragraphs, or a list and its items. |
| `story__byline` | The human author, when a story has one (a desk column). Absent otherwise. |
| `story__links` / `story__links-item` / `story__link-note` | The story's link list — a digest section's whole body; any engine's further reading. Absent when a story has none. |
| `story__data` / `story__data-row` / `story__data-label` / `story__data-value` / `story__data-note` | The story's data list — a wrap board's labeled figures and their motion. Absent when a story has none. |
| `story__footer` | The attribution footer. |
| `story__sources` / `story__source-link` | The sources line and each outlet link. Absent when a story has no sources. |
| `story__balance` | The balance measurement. |

## The page frame

| Class | Element |
| --- | --- |
| `page` / `page__main` / `page__measure` | Body, main, and the reading measure. |
| `page__nav` / `page__nav--between` / `page__nav-link` | The top navigation. |
| `masthead` / `masthead__wordmark` / `masthead__stop` / `masthead__motto` / `masthead__date` / `masthead__page-title` | The nameplate block. |
| `edition__stories` | The story stack with its hairline dividers. |
| `corrections` / `corrections__label` / `corrections__item` | The corrections section. |
| `fold` / `fold__label` / `fold__note` / `fold__reason` | The below-the-fold section. |
| `report` / `report__label` / `report__lines` | The run report. |
| `page__end` / `page__end--tight` | "The brief ends here." |
| `page-section` / `page-section--tight` / `section-label` | Home-page sections. |
| `page__footer` | The page footer block. |
| `desk` / `desk__label` / `desk__end` | One section of a sectioned paper on the edition page (generation 3): the desk, its label, and the line where it ends. Absent on a single-section paper. |

## The index

The front page of a sectioned paper carries its first section in full and
then every other desk compressed to one row per item — the paper's index
(generation 3). Absent on a single-section paper.

| Class | Element |
| --- | --- |
| `index` / `index__label` / `index__desks` | The index block, its "In today's paper" label, and the stack of desks. |
| `index__desk` / `index__desk-label` / `index__count` / `index__desk-end` | One desk: its linked name and item count, and the line where it ends. |
| `index__board` / `index__figure` / `index__figure-label` / `index__figure-value` / `index__figure-note` | The desk's figures, when it printed any (a board's rows). |
| `index__rows` / `index__row` / `index__kicker` / `index__headline` / `index__deck` / `index__source` | The rows: an optional kicker, the linked headline, the one-line deck, the source. |

## Home and sources furniture

| Class | Element |
| --- | --- |
| `about` | The about page's introduction block. |
| `masthead--front` / `masthead__ears` / `masthead__ear` / `masthead__ear--motto` / `masthead__ear--counts` | The front page's nameplate (generation 3): the date line under the wordmark, then the ears — the motto on one side, the other desks' counts on the other. |
| `lead` / `lead__end` | The front page's lead section in full, and the line where it ends. |
| `calendar` / `calendar__month` / `calendar__month-label` / `calendar__days` / `calendar__day` / `calendar__date` / `calendar__lead` / `calendar__count` | The archive as a calendar of mornings: month by month, each day its lead headline and how many desks printed. |
| `section-nav` / `section-nav__link` / `section-nav__link--none` / `section-nav__position` | A section page's neighbours: the previous and next desk, and "Section 2 of 4". |
| `feeds` | The front page's list of feeds — the paper's and each desk's. |
| `spectrum__side` / `spectrum__side--on` / `spectrum__side--off` / `spectrum__sep` | The side spectrum strip, monochrome since generation 3: every known position in order, filled where a story's coverage reaches and hollow where it does not, with dimmed separators. |
| `side--left` / `side--lean-left` / `side--center` / `side--lean-right` / `side--right` | The five known side labels, on the spectrum and the about page's rows. Deliberate skin hooks: the default theme gives them no colour, so the accent stays the only colour on the site. |
| `side-table` / `side-row` / `side-row__label` / `side-row__outlets` | The sources page's rows. |
| `subscribe` / `subscribe__input` / `subscribe__button` / `honeypot` / `visually-hidden` | The subscribe form. |

Classes with no rule in the default theme are deliberate skin hooks —
present in the markup so your stylesheet can reach them.
